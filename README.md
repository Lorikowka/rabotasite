# TeenWork

Платформа подработки и разовых заданий для подростков **14–18 лет**: вакансии, быстрые задания,
безопасный отклик, чат внутри платформы и автоматическая проверка объявлений по ТК РФ.

Реализация MVP по PRD ([`docs/prd.md`](docs/prd.md)).

---

## Что внутри

| Слой | Стек | Назначение |
| --- | --- | --- |
| `apps/web` | Next.js 15 (App Router), React 19, Tailwind v4, TypeScript | Мобильный-first интерфейс, SEO карточек вакансий |
| `apps/api` | Node.js, Fastify 5, TypeScript, Zod 4 | REST API + WebSocket-чат |
| `packages/shared` | TypeScript, Zod 4 | Доменные правила ТК РФ, DTO, схемы — общие для API и веба |
| `packages/db` | Drizzle ORM + `@libsql/client` (SQLite) | 11 таблиц, миграции, сид-данные |

Ключевая идея: **правила ТК РФ живут в `packages/shared/src/domain/`** и одинаково работают
в API (блокируют нарушения) и в браузере (живой предпросмотр в форме создания объявления).

## Быстрый старт

```bash
cd app
npm install                 # корневая папка монорепо (npm workspaces)
cp .env.example .env        # необязательно: все дефолты рабочие из коробки

npm run build:packages      # сборка @teenwork/shared и @teenwork/db
npm run db:migrate          # создать data/teenwork.db и применить миграции
npm run db:seed             # демо-данные: 8 пользователей, 6 объявлений, отклики, отзывы
```

Запуск в двух терминалах:

```bash
npm run dev -w @teenwork/api   # http://localhost:4000
npm run dev -w @teenwork/web   # http://localhost:3000
```

Или одной командой `npm run dev` (поднимает API; веб — отдельным терминалом).

### Проверка, что всё работает

```bash
npm run smoke                 # сквозной тест API: 39 проверок
npm test                      # 30 юнит-тестов домена + 12 интеграционных тестов API
```

Скрипт регистрирует подростка, работодателя и частного заказчика, откликается на вакансию,
принимает отклик, общается через WebSocket-чат, ловит антифрод-предупреждение, скачивает
PDF согласия родителей и трудового договора, оставляет отзыв и проверяет, что объявление
с ночной сменой на заводе блокируется правилами ТК РФ.

`npm test` прогоняет:

| Пакет | Что проверяет |
| --- | --- |
| `@teenwork/shared` | 30 юнит-тестов домена: возрастные когорты и лимиты ст. 94/95/92, ночная смена, категории, антифрод-паттерны, проверка объявлений по ТК РФ, бейджи, форматирование |
| `@teenwork/api` | 12 интеграционных тестов: Fastify поднимается в памяти (`app.inject()`) на временной SQLite, регистрация/вход/роли, создание объявлений (в т. ч. блокировка нарушений), модерация, отклики, чат с антифродом, отзывы |

## Ключевые механики

### 1. Проверка объявлений по ТК РФ (`packages/shared/src/domain/compliance.ts`)

`evaluateListing(draft, employerContext)` возвращает список нарушений с severity
(`block` / `review` / `warn`) и подсказки. Блокирующее нарушение → объявление не публикуется
(422), предупреждение → ручная модерация, замечание → показывается работодателю.

Проверяются:

- **ст. 94 ТК РФ** — лимит смены: до 4 ч/день для 14–15 лет, до 5 ч для 16–17, до 8 ч для 18;
- **ст. 95 ТК РФ** — ночные смены несовершеннолетним запрещены: ночной считается смена,
  начало которой приходится на время с 22:00 до 06:00, а также любая смена через полночь;
- **ст. 265 ТК РФ** — вредные и опасные условия, подземные работы, производство, стройка (18+);
- **ст. 266 ТК РФ** — работа в учебное время требует разрешения школы;
- категории с ограничением по возрасту (доставка и склад — с 16, производство — с 18);
- физлицам нельзя публиковать офлайн-задания в частном помещении;
- антифрод: залоги, «оплата за обучение», «пишите в телеграм», просьбы перевести деньги,
  обещания «лёгких денег».

### 2. Антифрод в чате

Любое сообщение сканируется на внешние контакты (телефон, Telegram, WhatsApp, VK, email,
внешние ссылки). Сообщение не блокируется — оно отправляется с предупреждением, которое
видит отправитель, а сама проверка попадает в очередь модерации:

- сообщение помечается `flagged` и попадает в `GET /api/admin/messages?flagged=true`;
- автоматически создаётся жалоба в `GET /api/admin/reports` с текстом сработавших правил;
- счётчик `flaggedMessages` виден в `GET /api/admin/stats`.

### 3. Скрытые контакты

Телефон и соцсети не передаются в DTO объявлений и откликов: в карточке вакансии
показывается только название компании, рейтинг и статус проверки ИНН.
Переписка идёт внутри платформы, где ведётся история и работает кнопка «Пожаловаться».

### 4. Отзывы и рейтинг

После выполненной работы и заказчик, и подросток могут оставить отзыв (оценка 1–5,
комментарий, бейджи). Отзыв можно оставить только один раз по отклику; средний рейтинг
пересчитывается автоматически и виден в профиле.

### 5. Документы (PDF)

`/api/documents/parent-consent` — бланк согласия родителя, `/api/documents/employment-contract` —
трудовой договор по шаблону ТК РФ. Кириллица рендерится через `pdf-lib` + `@pdf-lib/fontkit`
с Roboto TTF из `apps/api/assets/fonts/`.

### 6. Модерация

Объявления от юрлиц уходят в статус `moderation` до подтверждения ИНН. Администратор
одобряет или блокирует объявление через `/api/admin/listings/:id/moderate`,
жалобы собираются в `/api/admin/reports`, подозрительные сообщения — в
`/api/admin/messages?flagged=true`. Сводка по платформе — `/api/admin/stats`.

## API (кратко)

| Метод | Путь | Доступ | Назначение |
| --- | --- | --- | --- |
| `POST` | `/api/auth/register` | все | Регистрация (teen / business / individual) |
| `POST` | `/api/auth/login` | все | Запрос кода подтверждения |
| `POST` | `/api/auth/verify` | все | Вход по коду → httpOnly-кука `teenwork_session` |
| `GET` | `/api/auth/me` | сессия | Текущий пользователь + профиль |
| `GET` | `/api/listings` | все | Лента с фильтрами (категория, оплата, возраст, радиус, поиск) |
| `POST` | `/api/listings` | работодатель | Создание объявления с проверкой по ТК РФ |
| `GET/PATCH` | `/api/listings/:id` | все / автор | Карточка объявления / редактирование |
| `POST` | `/api/applications` | соискатель | Отклик |
| `PATCH` | `/api/applications/:id` | участник | Смена статуса: принять / отклонить / выполнить / отменить |
| `GET/POST` | `/api/applications/:id/messages` | участник | История чата / отправка сообщения |
| `WS` | `/api/chat/ws?applicationId=` | участник | Живой чат |
| `GET` | `/api/documents/parent-consent` | участник | PDF согласия родителей |
| `GET` | `/api/documents/employment-contract` | работодатель | PDF трудового договора |
| `POST` | `/api/reports` | сессия | Жалоба (в т. ч. срочная) |
| `POST` | `/api/reviews` | участник | Отзыв после выполненной работы |
| `GET` | `/api/users/:id/reviews` | все | Отзывы о пользователе |
| `GET` | `/api/admin/stats` | admin | Сводка: пользователи, объявления, модерация, жалобы, flagged-сообщения |
| `GET` | `/api/admin/listings` | admin | Очередь модерации (`?status=moderation`) |
| `POST` | `/api/admin/listings/:id/moderate` | admin | Модерация объявления |
| `GET` | `/api/admin/reports` | admin | Жалобы (в т. ч. автоматические из чата) |
| `GET` | `/api/admin/messages` | admin | Сообщения (`?flagged=true` — очередь антифрода) |
| `GET` | `/api/admin/users` | admin | Поиск пользователей |

## Что готово к проду и что дальше

Готово: вся воронка (регистрация → лента → отклик → чат → документы → отзывы),
модерация, антифрод, ТК РФ-проверки, PDF-документы, мобильный UI, SEO карточек.

Не сделано (осознанно вне MVP): реальный SMS-шлюз, платёжная система, push-уведомления,
загрузка фото (согласие родителей — только PDF-бланком), гео-поиск по адресам (сейчас
координаты и радиус), переход на Postgres (схема Drizzle готова — достаточно заменить драйвер).
